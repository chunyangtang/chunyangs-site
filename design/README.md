# Publication artwork

The website loads publication images from each folder in `src/content/publications/`. `thumbnail.svg` is the 4:3 listing image; `overview.png` is the larger figure used on the detail page.

- **AI-TEC:** [the live thumbnail](../src/content/publications/ai-agent-eye-clinic/thumbnail.svg) contains editable SVG shapes and text. Edit that file directly.
- **Nanophotonics:** [the editable source](publications/nanophotonics-overview-editable.svg) contains the complete embedded artwork and 29 editable text labels. The live thumbnail uses outlined text for consistent rendering across devices. Keep the editable source when exporting a replacement to the [publication folder](../src/content/publications/nanophotonics-optical-computing/).

The [artwork prompt](publications/nanophotonics-artwork-prompt.txt) describes the illustration's composition and finish. Preserve the 4:3 canvas and keep exported SVGs self-contained.
